a little world of anne <3  -  sixth monthversary website

EVERYTHING IS IN ONE FLAT FOLDER (no subfolders):
  index.html, style.css, script.js, README.txt,
  anne-001.jpg ... anne-019.jpg, and 3 font files (.woff2)

OPEN IT
  Double-click index.html. Works offline, no install needed.

DEPLOY (GitHub Pages, Netlify, Cloudflare Pages...)
  Upload the CONTENTS of this folder to the root of your repository.
  Keep all files together in the same place.

EDIT
  Messages, photo order and file names are at the top of script.js (PHOTOS).
  Colors are in :root at the top of style.css.
  To add a photo: put it in the folder and add an entry to PHOTOS
  (id, file, cat, msg, alt, w, h, pos).
  Categories with no photos are hidden automatically.

NOTES
  Fonts (Fraunces, Caveat) are bundled as .woff2 files here and are licensed
  under the SIL Open Font License 1.1 (https://openfontlicense.org).
  Photos are shown exactly as supplied. Cards only crop the preview;
  the full photo opens untouched when tapped.
